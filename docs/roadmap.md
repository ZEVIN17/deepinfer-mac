# Evidence-driven continuation / 后续验收

The joint Phase2 objective remains executable DS-derived methods plus fair superiority over two common frameworks at equal quality. Working0.1.0a2 is an experimental candidate; implemented features alone do not complete that goal.

1. Finish frozen-source9B8bit/4bit and14B quality/efficiency controls with fixed public subsets and local developer tasks; retain every failure and distinguish official scores from local subsets.
2. Measure main-model DS on/off, tuned fixed and legacy with equal warmup, full recovery cost and heldout prompts. Diagnose any full-token divergences before equal-quality speed claims.
3. Run native MLX-LM and oMLX with their actual cache features and equal weights/templates/sampling/cache budgets. Publish prompt/session distributions, clustered intervals and regressions; target≥15% in a predefined useful equal-quality workload, without hiding costs elsewhere.
4. If the method loses, retain the result and pursue another concretely mapped DS mechanism supported by profiling. Native-cache catchup and model-quality gains remain separately labeled.
5. Freeze source and verify installable artifacts/static site, memory limits, cancellation and repeated-session behavior. Preserve publisheda1 bytes and record candidate hashes.

Confidence Head, fullV4.1 CED/CSA2/MTP, continuous batching, sampled speculative residual acceptance and custom Metal kernels require separate weights/contracts/profiling evidence. Serial FIFO is not GPU batching. Frequent reload RSS retention remains unresolved.
